基础设置

常用功能集中在这里，适合日常快速调整。
电源策略
影响自动选择的调度倾向。均衡适合日常，性能会更激进，省电会更保守。
智能自动优化
根据 CPU 拓扑自动选择前台、后台和调度参数。开启后部分基础项会由自动策略接管。
触控 boost
写入内核暴露的 input boost 节点，用来改善触控后的短时响应。
温控保护
超过温度门限后收敛 top-app、foreground 与 background 的算力上限。
Vulkan 模式
全局模式会改系统渲染属性；按应用模式只对清单里的包名注入。
按应用包名
每行一个包名，例如 `com.example.game`。保存时会自动去重和排序。
fallback 轮询间隔
文件事件没有触发时，daemon 会按这个间隔重新套用配置。

高级选项

需要更细的 CPU、内存、I/O、GPU 与底层覆写值时再展开。
调度器调校
写入 `uclamp`、`schedtune` 与 `schedutil`。不确定设备内核行为时建议保持关闭。
内存调校
调整 MGLRU、swappiness、watermark 与 compaction。低内存设备可谨慎测试。
I/O 队列调校
调整 block queue 的预读、请求队列和亲和性。不同存储实现效果差异较大。
GPU 调校
尝试选择常见 GPU devfreq governor。游戏场景可测试，日常建议关闭。
后台小核限制
限制 background 组优先使用小核。省电可能更好，但后台任务可能更慢。
Lite 模式
降低部分调校强度，适合发热明显或续航优先的设备。
高级覆写值
空值或 `-1` 表示使用内置默认。错误数值可能导致性能或稳定性异常。
